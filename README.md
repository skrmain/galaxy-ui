# galaxy-ui

[![Netlify Status](https://api.netlify.com/api/v1/badges/53ee982c-d48c-4774-b1b9-0ffab7627fae/deploy-status)](https://app.netlify.com/projects/galaxy-ui/deploys)

A responsive frontend UI built with Vite and SCSS, deployed on Netlify.

**Live demo:** [galaxy-ui.netlify.app](https://galaxy-ui.netlify.app/)

## Getting Started

```bash
# Install dependencies
npm install

# Start the dev server
npm run dev

# Build for production
npm run build

# Preview the production build
npm run preview
```

## Tech Stack

- [Vite](https://vite.dev/)
- [Sass (SCSS)](https://sass-lang.com/)
- [Netlify](https://www.netlify.com/) (hosting and deploy previews)

## Deployment

Deployed on Netlify. Every pull request gets a deploy preview.
